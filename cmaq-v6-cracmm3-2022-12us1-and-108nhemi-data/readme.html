This readme refers to the data within the following dataset on AWS, uploaded for the CMAQv6 release by the CMAS Center last updated Oct. 7, 2026
CMAQv6 2022 CRACMMv3 12US1 and 108NHEMI dataset The dataverse entry for this data is here: CMAQv6 2022 CRACMMv3 12US1 and 108NHEMI Data

Downloading data from S3 Bucket

This dataset is available as part of the AWS Open Data Program, therefore egress fees are not charged to either the host or the person downloading the data.
Instructions for downloading the aws command line.

Instructions to Download AWS Command Line
Once you have it installed, you can use it without credentials.
Example commands:
To query how much data is in a bucket: 

aws s3 --no-sign-request ls --summarize --region=us-east-1 --human-readable --recursive s3://cmaq-v6-cracmm3-2022-12us1-and-108nhemi-data
